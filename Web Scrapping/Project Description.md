## 👉Flipkart Mobile Review Scrapping – Web Scrapping 

### Skills
Python, BeautifulSoup, Requests, Data Cleaning, Data Analysis, CSV Handling 

### Tool
Jupyter NoteBook

### Aim
To scrape customer reviews of mobile phones from the Flipkart website, clean and organize the data, and analyze insights such as review sentiments, ratings distribution, and key customer feedback trends.

### Steps
Performed data extraction, analysis, and cleaning; extracted meaningful insights; refined columns and structured data; and stored the final dataset in a CSV file. 

### Approach
-  Web Scraping – Used Python (BeautifulSoup & Requests) to extract reviews from Flipkart product pages. 
-  Data Extraction – Parsed HTML to capture review text, ratings, and reviewer details. 
-  Data Cleaning & Processing – Removed duplicates, handled missing values, and formatted columns.
-  Data Structuring – Organized data into a tabular structure using Pandas. 
-  Data Storage – Exported processed reviews to CSV for easy accessibility. 
-  Exploratory Analysis – Analyzed ratings distribution, review length, and recurring keywords. 

### Results 
Scraped and stored mobile review data from Flipkart, performed data cleaning and analysis to derive actionable insights, and developed a reusable dataset to support future analytical and visualization projects.
