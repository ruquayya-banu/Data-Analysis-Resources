# 👉HR Analytics Dashboard – Power BI 

### Skills:
Data Cleaning & Processing, Power Query, DAX, Power BI Dashboard Design, Data Visualization 

### Tool:
Power BI Desktop

### Aim:
To analyze HR data and create an interactive dashboard in Power BI that helps management track employee demographics, attrition, salary distribution, job roles, and overall workforce insights for better decision-making. 

### Steps:
• Imported and cleaned HR dataset in Power BI using Power Query. 
• Built calculated measures with DAX for KPIs like Attrition Rate, Average Age, Salary, and Tenure.
• Designed visualizations (bar, pie, line, and donut charts) with filters and slicers for dynamic analysis. 

### Approach:
•Data Import – Imported raw HR dataset into Power BI.
•Data Cleaning & Processing – Cleaned data using Power Query (removed nulls, duplicates, and inconsistencies).
•Data Modeling – Created relationships and applied transformations.
•DAX & Measures – Built calculated columns and measures for metrics like Attrition Rate, Avg. Age, Avg. Salary, etc. 
•Visualization – Designed visual elements such as Pie Charts, Bar Charts, Line Charts, and Cards. 
•Interactivity – Added filters and slicers (Department, Gender, Age, Education, Job Role). 
•Dashboard Design – Organized KPIs and visuals in a user-friendly layout. 
•Export & Sharing – Published/exported dashboard for stakeholders.

### Results:
Analyzed workforce data for 1,470 employees, identifying key trends in age, salary, and tenure. Uncovered a 0.8% attrition rate with highest churn among HR roles, employees aged 26–35, and those earning up to 5K. Delivered insights on education- and gender-based attrition patterns to support HR decision-making
