### Skills:- 
SQL, Database Design, Schema Creation, Joins, Aggregations, Data Analysis, CSV Import 

### Tool:-
MySQL Workbench

### Aim:- 
To design and implement a relational database for a grocery store, and analyze data to generate business insights on customers, products, suppliers, employees, and sales trends.

### Steps:- 
Designed schema with tables and applied keys & constraints and imported/validated data and wrote SQL queries for insights. Applied joins, aggregations, subqueries, and date functions. 

### Approach:- 
• Built a normalized schema with relationships. \
• Cleaned and validated imported data. \
• Developed queries for customer, sales, product, and supplier insights. 

### Results:- 
• Identified top customers, products, and suppliers by revenue. \
• Analyzed sales trends by month, date, and weekday/weekend. \
• Measured employee performance and order patterns.
